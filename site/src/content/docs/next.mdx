Java Core — это фундамент, а не финиш. После курса вы умеете читать и писать обычный Java-код, понимаете ООП, коллекции, исключения и потоки. Дальше стоит выбрать прикладное направление и закрепить знания проектом.

## Ближайшие темы

<Steps>

1. **SQL и базы данных.** Начните с PostgreSQL: `SELECT`, `JOIN`, `GROUP BY`, индексы, транзакции. Без SQL не обходится почти ни один бэкенд.
2. **Spring Boot.** REST-контроллеры, внедрение зависимостей, Spring Data JPA, валидация, обработка ошибок. Это самый частый стек в Java-вакансиях.
3. **Тестирование.** JUnit 5, AssertJ, Mockito, тест-контейнеры. Умение писать тесты отличает рабочего разработчика от «человека, который смотрел курс».
4. **Git и командная работа.** Ветки, pull request, code review, конфликты, осмысленные коммиты.
5. **Инструменты.** Maven/Gradle, Docker, логирование, базовый CI на GitHub Actions.

</Steps>

## Что сделать проектом

Лучше всего знания закрепляет небольшой сервис, который вы сами придумали и довели до работающего состояния. Например:

- **REST API для заметок или задач** на Spring Boot + PostgreSQL.
- **Парсер и агрегатор данных** с сохранением в базу и отчётом.
- **Телеграм-бот**, который ходит во внешний API и хранит историю.
- **Мини-библиотека** с выдачей книг, пользователями и сроками возврата.

Главное — не размер проекта, а завершённость: запуск, тесты, README и понятный сценарий использования.

## Полезные привычки

<Aside type="tip" title="Читайте чужой код">
  Открывайте исходники библиотек, которые используете. Начинайте с небольших классов: как устроен `ArrayList`, как работает `Optional`, как организован `ThreadPoolExecutor`.
</Aside>

- Пишите код руками, а не только читайте примеры.
- После каждой темы делайте маленькое упражнение.
- Возвращайтесь к старым урокам, если встретили незнакомую конструкцию.
- Заведите привычку объяснять код вслух или в заметках. Если не получается объяснить — вы ещё не поняли.
