Этот сайт — не отдельная копия курса, а представление репозитория. Java-код остаётся в `src/main/java`, а сайт читает его при сборке. Если изменить исходник и не обновить данные, CI это заметит.

## Три слоя

1. **Java-исходники** — единственный источник правды для кода: `src/main/java/org/baileyseyes/**`.
2. **Метаданные курса** — `site/src/data/course.mjs` и файлы `site/src/data/lessons/module-*.mjs`: порядок уроков, цели, идеи, упражнения и квизы.
3. **Сгенерированные данные** — `site/src/data/generated.json`: код файлов, номера строк, методы, типы и TODO. Генерируется скриптом `scripts/sync-course-data.mjs`.

<Aside type="note" title="Почему generated.json лежит в репозитории">
  Так сборка воспроизводима без Java и без запуска генератора в каждом окружении. CI всё равно проверяет, что файл соответствует исходникам.
</Aside>

## Команды

```bash
npm install          # зависимости сайта
npm run dev          # локальная разработка
npm run sync         # пересобрать generated.json из Java-исходников
npm run check:data   # проверить, что generated.json не устарел
npm run build        # production-сборка в dist/
npm run preview      # посмотреть production-сборку
```

Перед сборкой `prebuild` автоматически запускает `sync`.

## Как добавить урок

1. Добавьте объект урока в соответствующий `site/src/data/lessons/module-N.mjs`.
2. Укажите `sources` с путями к Java-файлам и `focus`:
   - `{ method: 'main' }` — показать метод;
   - `{ symbol: 'Human' }` — показать тип;
   - `{ lines: [10, 40] }` — показать диапазон строк;
   - `{ full: true }` — показать файл целиком.
3. Запустите `npm run sync`. Скрипт проверит, что файл, метод или тип существует, и обновит `generated.json`.
4. Добавьте `practice` и `quiz` — без них урок не станет уроком.
5. Проверьте сборку: `npm run check:data && npm run build`.

Если указать несуществующий метод, сборка упадёт с понятной ошибкой — это защита от «код на сайте разъехался с кодом в репозитории».

## Как устроена навигация

- **Главная** — точка входа и прогресс.
- **Модули** — обзор, список уроков и дополнительные материалы.
- **Уроки** — цель, идеи, код, вывод, практика, квиз.
- **Дополнительные материалы** — ссылки на файлы вне обязательного маршрута.
- **Прогресс** — локальные отметки, экспорт и импорт JSON.
- **Для автора** — эта страница, инвентарь файлов и карта маршрута.

## Технологии

- **Astro 5** и **Starlight** — статическая генерация, сайдбар, поиск, тёмная тема.
- **Expressive Code** — подсветка Java, копирование, номера строк.
- **Pagefind** — полнотекстовый поиск по собранным страницам.
- **localStorage** — прогресс без аккаунта и сервера.
- **GitHub Pages** — хостинг статической сборки.
